# Nikitha Vedant Madabhushi — Portfolio

This repository contains the React portfolio published at [nikithavedanth.github.io](https://nikithavedanth.github.io).

## Run locally

```bash
npm ci
npm start
```

## Deploy

The `Deploy to GitHub Pages` workflow builds the app and publishes the `build` directory whenever a commit is pushed to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
